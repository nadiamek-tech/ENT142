# ENT 142 · Fundamentals of Innovation and Entrepreneurship 2

Lab notes, Project 1 guide (one page per report section), report template and Report Lab for ENT 142 (Canadian University Dubai). Plain static HTML, no build step.

- `index.html`: course home (calendar, FAQ, help, submissions)
- `lectures.html`: weekly lab notes
- `week-05.html`: Week 5 · Prototyping
- `report.html`: report template (team drafts or the example)
- `report-lab.html`: Report Lab (11 steps from venture card to submitted report)
- `project-1.html`: Project 1 guide, one page per section
- `presentation.html`: Project 1 presentation and oral skills
- `assets/`: shared styles and lecture engine (same engine as the GED 102 lectures)

Open `index.html` in a browser, or serve the folder with GitHub Pages.
